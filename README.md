# GameMr - Mobile Game Store App

GameMr is a mobile application designed to provide a seamless shopping experience for gaming enthusiasts. Built with React Native, it incorporates modern design principles and advanced animations to enhance user interaction.

## Features

- **Smooth Animations:** Powered by React Native Reanimated for an engaging and dynamic experience.
- **Responsive Design:** Adapts perfectly to various screen sizes, ensuring an intuitive interface.
- **Intuitive Navigation:** Easy-to-use navigation for browsing and purchasing gaming products.

## Technologies Used

- React Native
- React Native Reanimated
- Expo CLI
- Redux (for state management)
- Firebase (backend services)
- TailwindCSS (for styling)

## Installation

To get started with GameMr, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/MHC32/GameMr.git
   ```

2. Navigate to the project directory:
   ```bash
   cd GameMr
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the application:
   ```bash
   expo start
   ```
